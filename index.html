SYSTEM ARCHITECTURE

How SmartTwin AI Operates

An end-to-end cyber-physical pipeline from synthetic telemetry to predictive maintenance intervention.

1

Simulated Sensor Readings

Physics-based simulation generates realistic CNC milling spindle dynamics (speed, torque, temps, wear, and vibration) at 2,000 ms intervals.

2

Telemetry Processing

FastAPI normalizes physical telemetry into bounded rolling buffers, validates engineering bounds, and tracks physical threshold rules.

3

AI Failure Prediction

Random Forest model evaluates multi-variate non-linear interactions to compute failure probability and diagnose root cause (TWF, HDF, PWF, OSF).

4

Maintenance Insights

Operators receive actionable prescriptive recommendations, deduplicated alerts, and persist service records directly to SQLite.

Project Overview & Objectives

SmartTwin AI is a Mechanical Engineering MDM mini project designed to demonstrate the implementation of an AI-based Digital Twin for smart manufacturing. Unexpected machinery downtime causes millions of dollars in losses across manufacturing sectors. Traditional reactive maintenance repairs machines only after catastrophic breakdown, while preventive maintenance discards functional cutting tooling prematurely.

By combining real-time kinematic digital twin visualization with a trained machine learning classification pipeline, SmartTwin AI detects degradation trajectories before catastrophic failure occurs, providing prescriptive maintenance guidance.

+-----------------------------------------------------------------------------------+ | SMARTTWIN AI FRONTEND | | (HTML5, Responsive Jade Pebble Morning CSS, High-DPI Canvas, Animated SVG CAD) | +-----------------------------------------+-----------------------------------------+ | HTTP REST / JSON | (Port 8000) v +-----------------------------------------------------------------------------------+ | FASTAPI PYTHON BACKEND SERVER | | (backend/main.py, Uvicorn ASGI Server, Pydantic Schema Validation) | +---------------------+---------------------------------------+---------------------+ | | v v +-------------------------------------+ +---------------------------------------+ | RANDOM FOREST ML PIPELINE | | SQLITE DATABASE | | - UCI AI4I 2020 (10,000 samples) | | (smarttwin.db, persistent storage) | | - Preprocessing & Scaler | | - sensor_readings - predictions | | - Balanced Class Weighting | | - alerts (dedup) - maintenance | | - TWF, HDF, PWF, OSF Diagnostics | +---------------------------------------+ +-------------------------------------+

Technology Stack

  • Frontend: Vanilla HTML5, CSS3 Custom Properties, High-DPI Canvas 2D API, Inline SVG
  • Backend: Python 3.10+, FastAPI, Uvicorn ASGI server, Pydantic v2
  • Machine Learning: Scikit-learn (RandomForestClassifier), NumPy, Joblib
  • Database: SQLite3 with event deduplication and indexed migrations
  • Testing: Pytest with FastAPI TestClient (30 automated regression tests)

Dataset & Scope

Dataset: Official UCI AI4I 2020 Predictive Maintenance Dataset with 10,000 real machining records.

Vibration Principle: Vibration is segregated as an independent physical simulation and is strictly excluded from ML model features to preserve scientific data integrity.

Future Scope: Hardware integration with ESP32 microcontrollers over MQTT and Remaining Useful Life (RUL) regression modeling.
